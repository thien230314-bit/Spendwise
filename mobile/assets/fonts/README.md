# SpendWise Mobile fonts

Official Google Fonts sources, with full Vietnamese glyph coverage (not Latin-only subsets).

- Be Vietnam Pro: Regular 400, Medium 500, SemiBold 600, Bold 700, Black 900.
  Body/copy, fields, labels, controls and the Web's black-weight Wise wordmark.
  Source revision: c13390277dfb1fcc7415d84ef7ef9cfc1e52f8c1.
  https://github.com/google/fonts/tree/c13390277dfb1fcc7415d84ef7ef9cfc1e52f8c1/ofl/bevietnampro
- Plus Jakarta Sans: Bold 700, ExtraBold 800.
  Section/page headings and auth/dashboard display hierarchy.
  Static instances generated with the existing fontTools utility from the official
  variable font, retaining the complete character map.
  Source revision: 8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5.
  https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/plusjakartasans

Web references: index.html, src/index.css, AuthPage, dashboard GreetingHeader /
PrimaryBalancePanel, WalletPage, TransferPage, BudgetPage, GoalsPage,
RecurringTransactionsTab, SettingsPage and Sidebar.
No italic, light, decorative serif or monospace faces are bundled.
Each family's SIL Open Font License is included alongside the assets.
