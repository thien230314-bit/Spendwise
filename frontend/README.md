# SpendWise Frontend Prototype

A personal and group financial management frontend prototype built with React, TypeScript, and Vite.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Animation:** Motion

## Running Locally

```bash
npm install
npm run dev
```

The application runs on `http://localhost:3000`.

## Runtime Notes
- **No API Key Required:** No Gemini API key is required for the current frontend runtime.
- **SpendWise AI:** Currently operates as a local frontend preview / rule-based assistant.
- **Bank Hub & SePay:** Payment tracking and SePay webhook confirmations run as DEV/Sandbox simulations until backend integration.
- **Data Persistence:** Client-side local storage is utilized for standalone interactive prototyping.
